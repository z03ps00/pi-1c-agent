# /install-memory-mcp — portable OpenViking + Cognee

One command that provisions **both** OpenViking (`knowledge`) and Cognee (`memory`) from assets in `mcp.optional/memory-stack/`. This is **our** stack. Do **not** install the upstream `comol/ai_rules_1c` Cognee MCP. `/install-cognee` and `/install-openviking` delegate here.

Memory stays opt-in: do not write `memory` / `knowledge` into default `mcp.json` until the user confirms.

## Docker policy (product)

Docker / Podman is allowed when the engine is reachable. Confirm before `docker compose up` / image pull.

1. Probe once: `docker ps` (or `docker version`). If it works, run the documented steps after confirmation.
2. If it fails or `PI_1C_BLOCK_DOCKER=1` is set, report Docker unavailable **once**, print the host copy-paste commands from `mcp.optional/memory-stack/README.md`, and do **not** retry docker in a loop.
3. `~/mcp-ctl.sh` / `~/mcp-host.sh` are **this lab’s** optional helpers, not the product path. Prefer `mcp.optional/memory-stack/scripts/memory-stack.sh`.

## Defaults (do not ask)

Apply these without prompting. The only user input is secrets (Router AI API key). OpenViking root/client keys are generated by the script if missing.

| Setting | Default |
|---|---|
| Provider | Router AI (`https://routerai.ru/api/v1`) |
| LLM | `qwen/qwen3.5-9b` (`hosted_vllm/${ROUTERAI_MODEL}` in Cognee, `reasoning_effort=none`) |
| Embeddings | `qwen/qwen3-embedding-8b`, dimension `1024` |
| Cognee DBs | sqlite / lancedb / ladybug; dataset `main_dataset`; agent scoping off |
| Ports | OpenViking `127.0.0.1:1933`, Cognee `127.0.0.1:8001` |
| Images | digest-pinned in `compose.yml` (tag fallbacks in `defaults.env`) |

**Ollama alternative** (only if the user explicitly selects it): LLM/VLM `qwen3.5:9b`, embeddings `bge-m3:latest` (dim 1024), no external API key. Switching providers later needs a reindex — do not hot-swap.

## Subcommands

| Invocation | Action |
|---|---|
| `/install-memory-mcp` | Ask consent, then bring up with Router AI |
| `/install-memory-mcp ollama` | Same pair, Ollama provider |
| `/install-memory-mcp status` | Health/status only (no install) |
| `/install-memory-mcp disable` | Stop the stack and remove only `memory`/`knowledge` from `mcp.json`; keep `./data` |

## Install steps (Router AI default)

1. Ask: use the paired OpenViking + Cognee memory stack in this profile? If no, stop.
2. If the user did not say `ollama`, use Router AI. Ask only for `ROUTERAI_API_KEY`. Do not ask for models, ports, or backends.
3. Copy `mcp.optional/memory-stack/secrets/routerai.env.example` → `secrets/routerai.env` if needed. Write the key locally (mode 0600). Never print the key, never commit it, never `remember` it.
4. Confirm Docker, then from the stack directory:

   ```bash
   ./scripts/memory-stack.sh up routerai
   ```

   Equivalent: `./scripts/memory-stack.sh up` (default provider).

5. On success the script reports both `/health` OK and writes `secrets/openviking-client.env` (do not echo the key).
6. Merge **both** fragments `mcp.optional/knowledge.json` and `mcp.optional/memory.json` into profile `mcp.json` (merge, never replace). Set:

   - `KNOWLEDGE_MCP_URL=http://127.0.0.1:1933/mcp`
   - `MEMORY_MCP_URL=http://127.0.0.1:8001/mcp`
   - `KNOWLEDGE_MCP_AUTHORIZATION` from the client key file (local env / secret store only)

7. Restart the client. Verify Cognee tools `remember`, `recall`, `search_tools` and OpenViking `find`, `search`, `read`, `remember`, `health`. Do not enable `forget` / `write` / `edit` unless the user explicitly asks.

## Ollama

Same flow without a provider key:

```bash
./scripts/memory-stack.sh up ollama
```

The script starts `pi-1c-memory-ollama`, pulls `qwen3.5:9b` and `bge-m3:latest`, then starts both MCP servers.

## Status

```bash
./scripts/memory-stack.sh status
```

Report **knowledge** (OpenViking, :1933) and **memory** (Cognee, :8001) separately. An absent Ollama container is normal for Router AI.

## Disable

```bash
./scripts/memory-stack.sh disable
```

Then remove only the `memory` and/or `knowledge` entries from `mcp.json`. Do not delete `mcp.optional/memory-stack/data/`. Leave 1C bundle, Vanessa, and other servers untouched. Disabling one family (remove `memory` only, or `knowledge` only) must not strip the other.

## Secrets

Never copy API keys, OpenViking root/client keys, or `.env` into git, AGENTS, handoffs, Cognee, or OpenViking `remember`. Shipped files are `secrets/*.env.example` with empty values.

## Failure

If a secret is missing, stop and name the missing file/variable. Do not invent keys. If Docker is down, print the `memory-stack.sh` commands for the host once.
