# Telegram-плагин Pi 1C

Общение с агентом через Telegram пока на стадии разработки. Поведение, команды и устойчивость ещё меняются. Вопросы и предложения по доработке приветствуются. Заранее спасибо за возможный вклад.

Отдельный процесс. Ядро `packages/pi-1c-agent` и панель `scripts/pi-1c-ctl.mjs` он не меняет. Команда `/telegram` появляется, когда пакет указан в `settings.json`.

Бот сам забирает сообщения у Telegram (long polling) и не открывает входящий порт. С этой машины должен открываться `api.telegram.org`. Процесс не запускают в netns `tunnel-awg-proxy-1`.

## Файлы

Рядом с профилем, не в git:

- `state/telegram/bot.token` — токен Bot API, права `0600`
- `state/telegram/config.json` — скопировать из `config.example.json`

`allowedUserIds` — числовые id Telegram. Пустой список никого не пускает. `allowedRoots` — каталоги, внутри которых можно выбрать проект. `pins` — кнопки каталогов.

## Подключение из агента

В сессии Pi: `/telegram`. Пустой вызов открывает раздел.

1. «Токен бота» — вставить токен из BotFather в поле. В текст команды токен не пишите.
2. «Подключить телефон» — агент покажет код. Отправьте этот код своему боту. Так записывается ваш Telegram id.
3. «Этот проект» — текущий каталог становится разрешённым корнем и кнопкой в боте.
4. «Запустить», если бот ещё не поднят.

После правки `settings.json` нужен перезапуск Pi, чтобы команда `/telegram` появилась.

`scripts/pi-1c-telegram` остаётся прямым запуском того же процесса. Файлы `state/telegram/` по-прежнему не попадают в git.
