# Tool policy

Use a structural capability before a wide search when that capability is available. Read is for a named file, an edit target, or a path a lookup already returned. Grep is for a missing structural capability, a failed lookup, literal text, or a non-structural artifact.

Do not read whole directories to locate a metadata object. Do not call live infobase mutation tools unless the user explicitly asked to change that infobase. Platform documentation tools answer platform questions, not customer configuration questions.
