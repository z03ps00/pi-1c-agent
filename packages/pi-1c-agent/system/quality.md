# Quality

Use the minimum sufficient workflow.

- Tier 0 is a consultation: orchestrator only.
- Tier 1 is a small local edit: developer, then verification.
- Tier 2 is ordinary development: explorer, developer, reviewer.
- Tier 3 is a complex change: explorer, architect, planner, developer, tester, reviewer.
- Tier 4 is critical risk: tier 3 plus an independent architecture review and an independent verifier.

A lower tier does not skip syntax check and does not replace ASK, PLAN, or BUILD. Implementation is incomplete until it is checked.
